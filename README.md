## 📖 About The Exhibition

**Hello — The Museum of First Words** is an interactive, editorial digital museum celebrating how humanity says hello across cultures, continents, and millennia.

From the conversational *"Konnichiwa"* (今日 は) in Japanese and *"Jambo"* in Swahili to ancient greetings like Classical Latin *"Salve"* and Sanskrit *"Namaste"*, the exhibition catalogs the phonetics, linguistic families, script origins, and cultural etiquette of human connection.

---

## 🌟 Exhibition Wings & Features

### 1. 🏷️ The Great Greeting Wall
- **120+ Curated Greetings**: Catalogs languages from Asia, Europe, Africa, the Americas, and Oceania.
- **Interactive Exhibit Labels**: Click any language card to open an editorial museum plaque detailing script origins, literal translation, speaker counts, and cultural etiquette.
- **Native Voice Pronunciations**: Synthesized audio playback powered by the Web Speech API with regional dialect synthesis.
- **Dynamic Filtering & Search**: Instant filter by geographical region, language family, or search query.

### 2. ☎️ The Rotary Phone Booth
- An interactive, animated 1970s dial phone listening station where visitors can dial country calling codes to hear native speakers and archival greeting transmissions.

### 3. 🎫 The Admission Ticket Builder
- A personalized, collectible museum ticket stamped with your arrival timestamp, unique serial code, and barcode.

### 4. 🔬 Speech Anatomy & Field Notes
- Visual breakdowns of speech mechanics, phonetic waveforms, and linguistic field notes on the evolution of greeting rituals across centuries.

### 5. 🎲 The Curator's Shuffle
- Instant randomized exhibit exploration discovering lesser-known regional dialects and indigenous languages with one click.

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/codewithabhiishek/Hello-Museum.git
cd Hello-Museum
npm install
```

### 2. Launch Local Exhibition
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** to explore the museum.

### 3. Run Automated Tests
```bash
npm test
```

### 4. Production Build & Typecheck
```bash
npm run typecheck
npm run build
```

## 🛠️ Architecture & Technologies

- **UI Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Engine**: [Vite 6](https://vitejs.dev/) with optimized modular vendor chunking
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with frosted museum glass placards, brutalist editorial typography, and cyber token accents
- **Audio & Haptic Engine**: Web Speech Synthesis API + Synthesized Web Audio API oscillators + tactile haptic feedback (`navigator.vibrate`)
- **Security & Quality**: 0 npm vulnerabilities (`npm audit` clean), Strix dual-honeypot form protection, and automated Node test suite

3. Include phonetic spelling, translation, region, and historical note
